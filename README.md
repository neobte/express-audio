# Reproductor Web de Música
Reproductor desarrollado con Javascript, HTML y css que permite reproducir archivos de audio desde una interfaz web moderna y fácil de usar.

## Características

- ▶️ Reproducir y pausar canciones.
- ⏮️ Navegar a la canción anterior.
- ⏭️ Navegar a la canción siguiente.
- 🔀 Modo aleatorio (Shuffle).
- 🔁 Repetición de canciones (All, one, none).
- 🎚️ Control de progreso mediante slider interactivo.
- 🔊 Control de volumen mediante slider y botón.
- 🔢 Visualización en tiempo real del nivel de volumen (ej. 50).
- ⏱️ Visualización y control del tiempo de reproducción.
- 📃 Interfaz de playlist integrada.
- 🎵 Selección directa de canciones desde la playlist mediante clic.
- 💻 Interfaz desarrollada con HTML y CSS.
